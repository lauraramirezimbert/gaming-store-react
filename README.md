# Gaming Store - Pre-Entrega React JS

Tienda e-commerce desarrollada con React JS y Vite, simulando un catálogo de productos gaming, vista de detalle, carrito de compras global con Context API y sistema de enrutamiento con React Router DOM.

## Tecnologías utilizadas
- React JS (Vite)
- React Router DOM
- Lucide React (Iconos)
- CSS / Estilos personalizados
